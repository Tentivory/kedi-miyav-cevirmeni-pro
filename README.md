# Kedi Miyav Çevirmeni Pro

## Giriş

Bu proje, insanlığın yüzyıllardır çözemediği en büyük soruna ışık tutmaktadır: İnsan dilinin kedilere anlaşılır hale getirilmesi. Gelişmiş algoritmalarımız sayesinde herhangi bir metin, saf miyav diline dönüştürülür. Bu, kedi-insan ilişkilerinde devrim yaratacaktır. Bilim dünyası şaşkın.

## Özellikler

- %100 miyav tabanlı çeviri
- Rastgele hısss ve mırır desteği
- Sonsuz döngü ile sürekli çeviri imkanı
- Bilimsel titizlikle test edilmiştir (kedi tarafından, bir kez)
- Hiçbir ek kütüphane gerektirmez çünkü kediler kütüphane sevmez

## Kurulum

Python 3 yeterlidir.

```bash
python kedi_miyav_cevirmeni.py
```

## Kullanım

Metin girin, miyav alın. Ciddiye alın. Kedi gülümsüyor.
